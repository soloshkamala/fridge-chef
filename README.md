# 🥗 RecipeVault (FridgeChef)

Вебплатформа для розумного підбору рецептів за наявними продуктами у холодильнику, планування харчування на день/тиждень, розрахунку КБЖВ та зручного керування покупками.

---

## ✨ Детальний функціонал проєкту

* **«Розумний холодильник» (Smart Fridge):** 
  * Інтерактивна панель вибору продуктів за категоріями (овочі, м'ясо, бакалія тощо).
  * Алгоритм пошуку страв за принципом наявності інгредієнтів із сортуванням за відсотком збігу («Є 4 з 5 продуктів»).
  * Гнучкі фільтри: час приготування, складність, тип прийому їжі, обмеження за калорійністю.

* **Калькулятор калорій та БЖВ:** 
  * Автоматичний розрахунок добової норми калорій та макронутрієнтів (білків, жирів, вуглеводів) на основі антропометричних даних користувача (вік, вага, зріст, рівень активності та мета: схуднення, набір маси, підтримка ваги).

* **Генератор раціонів (Meal Planner):** 
  * Складання індивідуального меню на день або цілий тиждень у межах персональної норми калорій.
  * Можливість ручної заміни страв та управління планом харчування у зручному календарі.

* **Автоматичний список покупок (Shopping List):** 
  * Екстракція та агрегація всіх відсутніх інгредієнтів із обраного тижневого раціону чи окремих рецептів.
  * Інтерактивний чек-лист для зручного використання під час походів по магазинах (можливість відзначати куплені товари).

* **Особистий кабінет (Dashboard):** 
  * Збереження улюблених рецептів та персональних раціонів у закладки.
  * Історія приготування та налаштування профільних даних, алергій чи виключень за продуктами.

---

## 📱 Структура сторінок застосунку

1. **Головна сторінка (Landing Page)** — презентація сервісу, переваги та швидкий старт.
2. **Сторінка авторизації (Auth)** — вхід, реєстрація та початковий онбординг користувача.
3. **Холодильник та рецепти** — підбір страв за наявними продуктами та перегляд покрокових рецептів.
4. **Конструктор раціонів та калькулятор** — розрахунок КБЖВ і планування меню на день/тиждень.
5. **Список покупок (Shopping List)** — інтерактивний чек-лист необхідних інгредієнтів для кулінарних планів.
6. **Особистий кабінет** — управління профілем, збереженими рецептами та налаштуваннями.
